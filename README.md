One short rant, at most 400 characters: a funny rant about a small everyday annoyance — a password reset email that arrives late, expires fast, and then rejects the new password for resembling the old one it made you forget. The entry: "The password reset email arrived 40 minutes late, expired in 10, and the new password I chose was rejected for being too much like the old one it made me forget."

## Run it

```sh
node main.ts
```

`main.ts` writes the rant to `ENTRY_OUTPUT` or `/output/entry.txt` — exactly one line, 161 characters, no trailing newline.
